Après une reconversion professionnelle réussie, j'ai obtenu successivement le titre professionnel **Développeur Web et Web Mobile (RNCP 5)** puis le diplôme **Concepteur Développeur d'Applications (RNCP 6)**.

À partir de septembre 2026, j'intégrerai Veolia Connected dans le cadre d'une alternance de deux ans. Cette nouvelle étape représente l'opportunité de poursuivre ma progression au sein d'une équipe de professionnels expérimentés et de mettre en pratique les compétences acquises au cours de ces quatre années d'investissement dans ma reconversion.

Mon objectif est de devenir rapidement autonome, gagner en confiance dans un environnement professionnel exigeant et apporter une réelle valeur ajoutée aux projets auxquels je participerai.

À plus long terme, je souhaite construire une expertise solide dans la conception et le développement d'applications, avec une orientation marquée vers le développement backend, l'architecture logicielle et l'intelligence artificielle.
